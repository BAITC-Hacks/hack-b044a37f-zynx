# Проверка перед защитой

## Что уже проверено

Автоматические тесты проверяют программную логику, сохранение и экспорт. Они **не доказывают** качество распознавания, диаризации или LLM на живой речи. Реальные модели в среде разработки не запускались из-за недоступных загрузок.

## Запись для демонстрации

Запишите двумя разными голосами короткую вымышленную встречу. Не имитируйте реальных людей; любые имена в сценарии условные. Один участник читает реплики Айданы, другой — Марата.

Айдана: Марат, подготовь отчёт по закупкам до 25 сентября.

Марат: Двадцать пятого не успею. Можно до 28 сентября?

Айдана: Да, согласовано: до 28 сентября. Есепке үш жеткізушінің бағасын қосыңыз.

Марат: Жақсы, үш жеткізушінің бағасын салыстырамын.

Айдана: Ещё подготовь письмо партнёрам. Срок отправки определим позже.

Марат: Хорошо, подготовлю письмо.

Ожидается после проверки: два основных поручения Марату — отчёт со сравнением трёх поставщиков, окончательный срок 28 сентября; письмо партнёрам без назначенной даты. Старый срок 25 сентября не должен остаться окончательным. Поручение про цены может быть отдельным подпунктом отчёта; это допустимо при сохранённой связи и без выдуманного нового срока.

## Таблица измерений

Заполняется командой после фактического запуска; значения заранее не заявляются.

| Проверка | Вход | Ожидание | Фактический результат |
|---|---|---|---|
| Русский | 30–60 секунд, 2 голоса | Смысл, имена и сроки сохранены | Не измерено |
| Қазақша | 30–60 секунд, 2 голоса | Қазақша мәтіннің мағынасы сақталады | Не измерено |
| Смешанная речь | Сценарий выше | Оба языка без перевода в английский | Не измерено |
| Диаризация | 2 разных голоса | Два устойчивых SPEAKER ID | Не измерено |
| Изменённый срок | 25 → 28 сентября | Окончательная дата 28 сентября | Не измерено |
| Срок не назван | Письмо партнёрам | Пустая дата и запрос уточнения | Не измерено |
| Ответственный | Поручает Айдана, делает Марат | Исполнитель Марат | Не измерено |
| Длительность | 1 минута записи | Замер времени на целевом ПК | Не измерено |
| Без сети | Все веса предварительно скачаны | Полный проход без интернета | Не измерено |

Дополнительно проверьте примеры `examples/demo.json`. Во втором примере должны быть аудит Нурлану с согласованным сроком 15 октября, запрос заключения Айгуль со сроком «к среде» для уточнения даты, согласование бюджета Тимуру с Нурланом на текущей неделе. Сроки «две недели» и «три недели» не должны конкурировать с окончательной явной датой.

Для качества транскрипта посчитайте CER/WER по вручную проверенной расшифровке. Для поручений сравните ожидаемые действие/ответственного/срок и посчитайте пропуски и ложные поручения. Для диаризации запишите хотя бы долю ошибочно приписанных реплик; полноценная DER требует временной разметки. Эти метрики пока не измерены.

## Ручная проверка интерфейса

Открытие на Windows Chrome/Edge → демо → три карточки → изменение статуса → «Сохранить правки» → перезагрузка страницы → выбор сохранённого совещания → проверка правок → PDF/DOCX → удаление тестовой встречи. Проверьте, что файл с казахскими буквами читается в Word/WPS. Рекомендуется также открыть интерфейс на узком экране.
