# Локальный запуск в VS Code (Windows)

## Быстрый старт

1. Скачайте ZIP репозитория через **Code → Download ZIP**, распакуйте архив и откройте в VS Code папку, где лежит `app.py`.
2. Установите Python 3.12 с [python.org](https://www.python.org/downloads/). В установщике включите **Add Python to PATH**.
3. В VS Code откройте **Terminal → New Terminal** и выполните:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Выберите окружение: **Ctrl+Shift+P → Python: Select Interpreter → .venv**.
5. В проводнике VS Code откройте **app.py** и нажмите **Run Python File** (▶ в правом верхнем углу).
6. Оставьте терминал запущенным и откройте [http://127.0.0.1:8765](http://127.0.0.1:8765).

Также после шага 3 можно дважды нажать `start.cmd`.

## Что запускается

Без дополнительных моделей доступен демо-режим для проверки интерфейса. Чтобы запустить обработку речи и локальный AI, установите Ollama и скачайте локальную языковую модель. Для аудио установите зависимости из `requirements-audio.txt` и загрузите веса Whisper; для разделения говорящих настройте pyannote по инструкции в [README.md](README.md). Модели в Git не хранятся и в ZIP не включены.

Обработка аудио и текста выполняется локально; установка библиотек и загрузка весов требуют интернета.
